WinDeck 사용 안내
=================

화면에 떠 있는 버튼 패널(8·12·16칸)입니다.
버튼을 누르면 폴더·웹사이트·프로그램이 열리거나, 지정한 문장·단축키가 입력됩니다.

최신 버전 받기: https://github.com/musiqsb-svg/WinDeck/releases/latest
※ Microsoft Edge로는 설치되지 않습니다. Chrome·웨일·Firefox 등 다른 브라우저로 내려받으세요.
(1.3.0 부터는 새 버전이 나오면 트레이 알림을 눌러 바로 업데이트할 수 있습니다)


■ 처음 실행할 때 "Windows의 PC 보호" 창이 뜨면

  팀 내부용 프로그램이라 전자 서명이 없어서 나오는 안내입니다.
  [추가 정보] → [실행] 을 누르면 됩니다.


■ 기본 사용법

  버튼 클릭 ................ 지정한 동작 실행
  버튼 우클릭 .............. 편집 · 복사 · 붙여넣기 · 비우기 · 다른 페이지로 옮기기
  버튼 끌기 ................ 자리 옮기기 (다른 버튼 위에 놓으면 두 버튼이 자리를 바꿈)
                             끈 채로 패널 왼쪽·오른쪽 가장자리나 ◀ ▶ 위에 잠시 머물면 페이지가 넘어감
                             끄는 중에 마우스 오른쪽 버튼을 누르면 끌기를 취소함
  빈 칸 클릭 ............... 새 버튼 만들기
  버튼 위에 마우스 올리기 .. 버튼 설명 보기
  빈 칸에 끌어다 놓기 ...... 파일 · 폴더 · 웹 링크로 버튼 만들기 (버튼 이름을 묻는 창이 뜸, Enter = 자동 이름)
                             웹 링크는 그 사이트의 아이콘도 자동으로 들어감
  위쪽 막대 끌기 ........... 패널 옮기기
  마우스 휠 / ◀ ▶ ......... 페이지 넘기기
  Ctrl + ` ................ 패널 숨기기 / 다시 보이기  (` 는 Tab 키 바로 위, 숫자 1 왼쪽 키)
  Ctrl + Alt + ← / → ...... 이전 / 다음 페이지 (패널이 숨겨져 있으면 나타남)
  트레이 아이콘 ............ 숨기기·보이기, 설정, 종료 (작업 표시줄 오른쪽, 안 보이면 ^ 클릭)

  문장 입력 버튼은 메모장·메신저·브라우저 등에 커서를 둔 상태에서 누르면
  그 자리에 바로 입력됩니다.

  끌어서 다른 페이지로: 버튼을 끈 채로 패널 오른쪽 가장자리(조금 밖까지)에 머물면 다음 페이지,
  왼쪽 가장자리에 머물면 이전 페이지로 넘어갑니다. 그 가장자리에 파란 막대가 차오르고, 다 차면 넘어갑니다.
  계속 머물면 1초마다 한 페이지씩 더 넘어갑니다. 마지막 페이지 다음은 첫 페이지입니다.
  넘어간 페이지의 칸에 놓으면 버튼이 그 칸으로 갑니다.
  그 칸에 버튼이 있으면 두 버튼이 자리를 바꿉니다 (그 버튼은 끌어 온 버튼의 원래 페이지·자리로 감).
  패널 밖에 놓으면 아무것도 바뀌지 않고, 패널은 원래 페이지로 돌아갑니다.

  다른 페이지로 옮기기: 버튼 우클릭 → [다른 페이지로 옮기기] → 페이지 선택.
  버튼은 그 페이지의 첫 빈칸으로 들어가고, 패널은 지금 페이지에 남습니다.
  빈칸이 없는 페이지는 "(빈칸 없음)"으로 표시됩니다. [새 페이지를 만들어 옮기기…]도 있습니다.

  브라우저 주소 창 왼쪽의 자물쇠 아이콘을 끌어다 놓으면 페이지 제목이 자동 이름으로 들어갑니다.

  버튼 편집 창에서 '바로 실행 단축키'를 지정하면 패널을 열지 않고도 키보드로 버튼을 실행합니다.
  페이지마다 바로가기 단축키도 지정할 수 있습니다 (설정 → 페이지 → 단축키).
  아이콘은 버튼 편집 창의 [아이콘 모음]에서 입체(3D)·플랫(2D) 기본 아이콘 90종 중에 고를 수 있습니다.

  사이트 아이콘: 웹 링크를 끌어다 놓으면 그 사이트의 아이콘을 받아 버튼에 넣습니다.
    - 이미 만든 링크 버튼: 버튼 편집 창의 [사이트 아이콘 넣기], 또는 설정 → 페이지 → [사이트 아이콘…]
      ([사이트 아이콘…]은 아이콘이 없는 링크 버튼 전체에 넣고, 직접 고른 아이콘은 바꾸지 않습니다)
    - 아이콘은 그 사이트에서만 받습니다. 막힌 사이트·사내 사이트는 기본 모양으로 둡니다.
    - 로그인이 필요한 사이트는 로그인 화면의 아이콘이 들어갈 수 있습니다. [아이콘 모음]이나 [내 이미지]로 바꾸세요.


■ 설정 (패널 오른쪽 위 톱니바퀴)

  단축키 · 버튼 크기 · 버튼 수(8·12·16) · 가로/세로 배치 · 배경(단색·이미지) · 투명도
  커서 위치에 표시 · 윈도우 시작 시 자동 실행
  버튼 수를 줄여도 뒤쪽 버튼은 지워지지 않고 숨겨지며, 다시 늘리면 제자리에 나타납니다.
  페이지 추가·이름 변경 · 설정 내보내기 · 불러오기 · 백업 되돌리기 · 새 버전 자동 확인

  "단축키를 등록하지 못했습니다" 알림이 뜨면 다른 프로그램이 같은 키를 쓰는 것이니
  설정에서 다른 키로 바꾸세요.


■ 새 버전 업데이트

  새 버전이 나오면 트레이에 알림이 뜹니다. 알림을 누르고 [지금 업데이트]를 누르면
  설정을 저장·백업한 뒤 새 버전을 받아 검사하고, 설치가 끝나면 WinDeck 이 다시 켜집니다.
  업데이트를 끝내지 못하면 쓰던 버전이 다시 켜지고 트레이 알림으로 알려 줍니다. 버튼과 설정은 그대로입니다.
  알림을 놓쳤다면 트레이 아이콘 우클릭 → "새 버전 설치…" 또는 "업데이트 확인…".
  (설정 → 일반 에서 자동 확인을 끄거나 [지금 확인]을 누를 수 있습니다)


■ 설정이 예전 상태로 돌아갔을 때

  설정 → 백업 → 목록에서 원하는 때를 골라 [선택한 백업으로 되돌리기].
  하루 한 번, 그리고 설정을 바꾸거나 불러오거나 업데이트하기 직전에 자동으로 백업됩니다 (최근 20개).
  다른 위치에 더 최근 설정이 있으면, 처음 실행할 때 불러올지 물어봅니다.


■ 내 버튼을 동료와 나누기

  보내는 사람: 설정 → 백업 → [설정 내보내기] 로 .json 파일 저장 → 메신저·메일로 전달
  받는 사람: 설정 → 백업 → [설정 불러오기] (다운로드 폴더에서 열림)
            또는 받은 .json 파일을 패널에 끌어다 놓기
  불러온 내용은 WinDeck 에 저장되므로, 받은 파일은 바탕 화면·다운로드 어디에 두어도 되고
  불러온 뒤 지워도 됩니다. 불러오기 직전 내 설정은 자동으로 백업됩니다.
  보낸 사람 PC 의 바탕 화면·다운로드·문서 폴더로 만든 버튼은 내 PC 의 같은 폴더로 열립니다.


■ 설치와 제거

  받은 WinDeck-x.x.x.zip 을 풀면 아래 3개가 있습니다.
    WinDeck 설치.exe   WinDeck 제거.exe   app 폴더 (WinDeck 이 쓰는 파일)

  설치: 'WinDeck 설치.exe' 실행 → [설치]
    - 관리자 권한 없이 %LOCALAPPDATA%\Programs\WinDeck 에 설치됩니다.
    - 시작 메뉴와 바탕 화면에서 실행합니다. 새 버전도 같은 방법으로 덮어 설치합니다.
  제거: Windows 설정 → 앱 → 설치된 앱 → WinDeck → 제거  (또는 'WinDeck 제거.exe')
    - 버튼 설정도 지울지 묻습니다. [아니요]면 다시 설치했을 때 지금 버튼을 그대로 씁니다.
    - 설치가 만든 파일만 지웁니다. 설치 폴더에 직접 넣어 둔 파일이 있으면 그 파일과 폴더는 남습니다.
  설정 저장 위치: %APPDATA%\WinDeck

  1.3 이하 포터블판을 쓰던 분
    - 1.4.0 부터 포터블판은 없습니다.
    - 새 버전을 처음 켜면 WinDeckData 폴더의 버튼 설정을 %APPDATA%\WinDeck 으로 옮깁니다.
    - 옛 포터블 폴더는 그대로 남습니다. 새 버전에서 버튼을 확인한 뒤 지워도 됩니다.


■ 참고

  - 관리자 권한으로 실행된 프로그램 창에는 문장·단축키가 입력되지 않습니다.
  - 입력이 안 되는 프로그램은 버튼 편집에서 '붙여넣기 방식'을 켜 보세요.
  - WinDeck 은 한 번에 하나만 실행됩니다.
  - 사용 조건: 같은 폴더의 LICENSE.txt, NOTICE.txt
    비상업적 용도로 무료로 쓸 수 있습니다. 허락 없이 복사·수정·재배포할 수 없습니다.
