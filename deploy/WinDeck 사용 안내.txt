WinDeck 사용 안내
=================

화면에 떠 있는 버튼 패널(8·12·16칸)입니다.
버튼을 누르면 폴더·웹사이트·프로그램이 열리거나, 지정한 문장·단축키가 입력됩니다.

최신 버전 받기: https://github.com/hopenesttt-prog/WinDeck/releases/latest
※ Microsoft Edge로는 설치되지 않습니다. Chrome·웨일·Firefox 등 다른 브라우저로 내려받으세요.
(새 버전은 설치판을 덮어 설치하면 버튼 설정이 그대로 유지됩니다)


■ 처음 실행할 때 "Windows의 PC 보호" 창이 뜨면

  팀 내부용 프로그램이라 전자 서명이 없어서 나오는 안내입니다.
  [추가 정보] → [실행] 을 누르면 됩니다.


■ 기본 사용법

  버튼 클릭 ................ 지정한 동작 실행
  버튼 우클릭 .............. 편집 · 복사 · 붙여넣기 · 비우기
  빈 칸 클릭 ............... 새 버튼 만들기
  버튼 위에 마우스 올리기 .. 버튼 설명 보기
  빈 칸에 끌어다 놓기 ...... 파일 · 폴더 · 웹 링크로 버튼 자동 생성
  위쪽 막대 끌기 ........... 패널 옮기기
  마우스 휠 / ◀ ▶ ......... 페이지 넘기기
  Ctrl + ` ................ 패널 숨기기 / 다시 보이기  (` 는 Tab 키 바로 위, 숫자 1 왼쪽 키)
  Ctrl + Alt + ← / → ...... 이전 / 다음 페이지 (패널이 숨겨져 있으면 나타남)
  트레이 아이콘 ............ 숨기기·보이기, 설정, 종료 (작업 표시줄 오른쪽, 안 보이면 ^ 클릭)

  문장 입력 버튼은 메모장·메신저·브라우저 등에 커서를 둔 상태에서 누르면
  그 자리에 바로 입력됩니다.

  버튼 편집 창에서 '바로 실행 단축키'를 지정하면 패널을 열지 않고도 키보드로 버튼을 실행합니다.
  페이지마다 바로가기 단축키도 지정할 수 있습니다 (설정 → 페이지 → 단축키).
  아이콘은 버튼 편집 창의 [아이콘 모음]에서 입체(3D)·플랫(2D) 기본 아이콘 90종 중에 고를 수 있습니다.


■ 설정 (패널 오른쪽 위 톱니바퀴)

  단축키 · 버튼 크기 · 버튼 수(8·12·16) · 가로/세로 배치 · 배경(단색·이미지) · 투명도
  커서 위치에 표시 · 윈도우 시작 시 자동 실행
  버튼 수를 줄여도 뒤쪽 버튼은 지워지지 않고 숨겨지며, 다시 늘리면 제자리에 나타납니다.
  페이지 추가·이름 변경 · 설정 내보내기(백업) · 불러오기

  "단축키를 등록하지 못했습니다" 알림이 뜨면 다른 프로그램이 같은 키를 쓰는 것이니
  설정에서 다른 키로 바꾸세요.


■ 내 버튼을 동료와 나누기

  설정 → [설정 내보내기] 로 .json 파일 저장 → 동료가 설정 → [설정 불러오기]


■ 설치판과 포터블판

  설치판 (WinDeck-Setup-x.x.x.exe)
    - 관리자 권한 없이 설치됩니다. 시작 메뉴에서 실행합니다.
    - 제거: Windows 설정 → 앱 → 설치된 앱 → WinDeck → 제거
    - 설정 저장 위치: %APPDATA%\WinDeck

  포터블판 (WinDeck-Portable-x.x.x.zip)
    - 압축을 푼 폴더의 WinDeck.exe 를 실행합니다. 설치가 필요 없습니다.
    - 설정은 같은 폴더의 WinDeckData 폴더에 저장됩니다. 폴더째 USB 등에 옮겨 쓸 수 있습니다.
    - 삭제: 폴더를 지우면 끝입니다. (자동 실행을 켰다면 먼저 설정에서 끄세요)
    - 바탕 화면이나 문서 폴더처럼 쓰기 가능한 곳에 압축을 푸세요.


■ 참고

  - 관리자 권한으로 실행된 프로그램 창에는 문장·단축키가 입력되지 않습니다.
  - 입력이 안 되는 프로그램은 버튼 편집에서 '붙여넣기 방식'을 켜 보세요.
  - 설치판과 포터블판은 동시에 실행되지 않습니다. 하나만 사용하세요.
